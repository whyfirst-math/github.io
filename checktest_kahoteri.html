STEP 1

まず公式を覚える

公式暗記フラッシュ
sin(α+β) = ?
sinα cosβ + cosα sinβ
覚え方の最短ルート
  • sin：真ん中の符号はそのまま
  • cos：真ん中の符号が反対
  • tan：上はそのまま、下は反対

※ 最後は必ず公式そのものを書けるようにしよう。

隠した状態でフラッシュに挑戦しよう。
sin(α+β) = sinα cosβ + cosα sinβ
sin(α−β) = sinα cosβ − cosα sinβ
cos(α+β) = cosα cosβ − sinα sinβ
cos(α−β) = cosα cosβ + sinα sinβ
tan(α+β) = tanα + tanβ1 − tanα tanβ
tan(α−β) = tanα − tanβ1 + tanα tanβ
テストで一番多いミス： cos の + と −。
cos(α+β) は「−」、cos(α−β) は「＋」です。
STEP 2

度数法型：有名角2つに分ける

合言葉： 15°・75°・105°を見たら、30°・45°・60°の組合せに分ける。

例題　sin105° を求めよ。
  1. 105° = 60° + 45° と分ける。
  2. sin(60°+45°) = sin60°cos45° + cos60°sin45°
  3. = (√32)(√22) + (12)(√22)
  4. = √6 + √24
例題　tan15° を求めよ。
  1. 15° = 60° − 45° と分ける。
  2. tan(60°−45°) = tan60° − tan45°1 + tan60°tan45°
  3. = √3 − 11 + √3
  4. = 2 − √3
確認： 15°は第1象限なので tan は正。答えが正になっていることも確認しよう。

STEP 3

弧度法型：見た目が違うだけ

712π は 105°。でも、105°に直さなくても 13π + 14π と見ればOKです。

例題　cos(712π) を求めよ。
  1. 712π = 13π + 14π
  2. cos(13π+14π) = cos(13π)cos(14π) − sin(13π)sin(14π)
  3. = (12)(√22) − (√32)(√22)
  4. = √2 − √64
符号チェック： 712π = 105° は第2象限なので cos は負です。
例題　tan(712π) を求めよ。
  1. 712π = 13π + 14π と分ける。
  2. tan(13π+14π) = tan(13π) + tan(14π)1 − tan(13π)tan(14π)
  3. = √3 + 11 − √3
  4. = −2 − √3
ポイント： 弧度法でもやることは同じ。まず「30°・45°・60°に対応するπ」を探します。
大事： ②と③は同じ問題です。違うのは「度」か「π」かだけ。sin・cos・tanすべて同じ考え方です。

STEP 4

象限型：手順を固定する

この4手順だけ： ①象限を見る → ②足りない sin / cos を出す → ③公式を書く → ④代入
例題　αは第3象限、βは第4象限。sinα = −513, cosβ = 45 のとき、sin(α+β), cos(α−β) を求めよ。
  1. 第3象限なので cosα は負。cosα = −1213
  2. 第4象限なので sinβ は負。sinβ = −35
  3. sin(α+β) = sinαcosβ + cosαsinβ
    = (−513)(45) + (−1213)(−35) = 1665
  4. cos(α−β) = cosαcosβ + sinαsinβ
    = (−1213)(45) + (−513)(−35) = −3365

STEP 5

2直線のなす角：傾き＝tan

例題　y = 3x, y = 12x のなす角 θ を求めよ。ただし 0<θ<12π。
  1. それぞれの傾きを tan と見る。tanα = 3, tanβ = 12
  2. なす角を θ = α−β とする。
  3. tanθ = 3 − 121 + 3×12 = 52 ÷ 52 = 1
  4. 0<θ<12π だから θ = 14π
忘れやすい： 直線の問題では、最初に「傾き＝tan」を書く。
